# 关于我

你好，我是**张志威**。

我关注**具身智能、机器人、人工智能与世界模型**，希望机器人能够在与环境的交互中积累经验，更好地感知世界、理解任务、学习技能，并在变化的场景中做出合适的决策。

**让机器人更智能，是我持续探索的方向。**

这个网站记录我的学习、实践与思考，也保存那些在编程和开发过程中值得反复查阅的问题。

## 我关注的方向 {#focus}

| 方向 | 我关心的问题 |
| --- | --- |
| 具身智能 | 感知、决策与行动如何通过和环境的交互联系起来？ |
| 机器人 | 如何把建模、仿真、规划与控制连接成能够实际运行的系统？ |
| 人工智能 | 如何通过学习获得更好的任务能力，并把这些能力用到机器人上？ |
| 世界模型 | 如何表征环境、预测变化，并利用这些理解辅助规划与决策？ |
